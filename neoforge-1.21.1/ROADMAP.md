# Roadmap — что осталось до «настоящего Mappet»

Сравнение с оригинальным Mappet (1.12/1.16) и BBS. Отсортировано по
важности для геймплея.

## Высокий приоритет

1. **Вкладка Factions в дашборде.** Сейчас фракции редактируются только
   через JSON-файлы (`scriptbound/factions/`). Нужна полноценная вкладка
   с порогами, цветами и списком.
2. **Условия в choices диалогов.** В Mappet каждый вариант ответа может
   иметь condition (показывать только при квесте/стейте). У нас choices —
   только текст + триггер.
3. **Quest chains / зависимые квесты.** Квест открывается после другого,
   авто-выдача следующего, отображение цепочки.
4. **Больше событийных нод:** item use, block break/place, entity kill
   (сейчас kill есть только как objective квеста), таймер/расписание
   (cron-нода), dimension change.
5. **NPC онлайн-редактор.** В Mappet NPC редактируется через GUI с
   превью модели. У нас — формы + JSON. Нужен биндинг BBS-форм
   с превью прямо в дашборде.

## Средний приоритет

6. **Crafting tables (кастомные крафты) Mappet** — отдельные крафт-столы
   с уникальными рецептами, открываемые триггером.
7. **HUD-сцены** — кастомные оверлеи (текст, картинки, таймеры) поверх
   экрана, управляемые триггерами/скриптами.
8. **Состояния NPC (NPC states)** — один блюпринт, несколько вариантов
   поведения/диалога в зависимости от стейта мира.
9. **Расширение Script API до уровня Mappet:** доступ к миру
   (блоки, энтити, погода, время), inventory API, raytrace, particles,
   NBT-доступ, события подписки из скриптов.
10. **Регионы произвольной формы** (сейчас только бокс вокруг блока):
    полигональные/мульти-боксы, видимая визуализация границ.
11. **Журнал квестов (GUI)** — сейчас квесты видны только командой;
    нужен экран журнала с прогрессом целей.

## Низкий приоритет / полировка

12. **Морф-атаки и боевые NPC** — агрессивное поведение, атака игрока
    при hostile-отношении (сейчас NPC только отказывается говорить).
13. **Импорт/экспорт контента** (zip-пак квестов/диалогов/флоу для
    переноса между мирами).
14. **Мультиселект и копипаст нод** во флоу-редакторе, группировка,
    выравнивание, миникарта.
15. **Поиск по всем типам контента** сразу (глобальный поиск в дашборде).
16. **Локализация строк** (lang-файлы для диалогов).
17. **Права доступа** — кто из игроков может открывать дашборд
    (сейчас op-permission уровня команды).
